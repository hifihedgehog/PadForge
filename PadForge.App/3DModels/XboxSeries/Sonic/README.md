# Sonic the Hedgehog skin

Custom shell artwork based on the [Razer Sonic the Hedgehog Limited Edition controller](https://www.razer.com/eu-en/console-controllers/sonic-xbox-controller-and-charging-stand).
Sonic the Hedgehog characters and artwork belong to SEGA. Razer and Xbox marks belong to their respective owners.

Shell.png uses the Carbon/Robot UV layout. The model shares Carbon's geometry, control textures, moving decals, and transparent button covers.
